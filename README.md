## Dataset

- Training images: `60,000`
- Test images: `10,000`
- Input size: `784` flattened pixels
- Batch size: `128`

The two personal focus classes used for class-specific evaluation are:

- Class 2: Pullover
- Class 8: Bag

## Models

### Fully Connected Autoencoder

The FC-AE uses a deterministic latent representation:

```text
784 → 256 → 64 → 256 → 784
```

The encoder compresses each image into a 64-dimensional vector. The decoder reconstructs the image from that vector. ReLU activations are used in the hidden layers, and a sigmoid output keeps reconstructed pixels between zero and one.

The FC-AE is trained with mean squared error (MSE):

```text
MSE = mean((original_image - reconstructed_image)^2)
```

### Variational Autoencoder

The VAE uses a probabilistic 20-dimensional latent representation. Instead of producing one fixed latent vector, the encoder produces:

- A mean vector `mu`
- A log-variance vector `logvar`

A latent vector is sampled using the reparameterization trick:

```text
z = mu + exp(0.5 * logvar) * epsilon
```

where `epsilon` is sampled from a standard normal distribution.

The VAE objective combines reconstruction loss and KL-divergence loss:

```text
VAE loss = reconstruction loss + KL-divergence loss
```

The reconstruction term encourages accurate images, while the KL term regularizes the latent space toward a standard normal distribution. This regularized latent space allows the VAE to generate new samples.

## GAN Concepts Covered

The notebook explains the two networks in a GAN:

- The generator creates synthetic samples from random noise.
- The discriminator predicts whether a sample is real or generated.

The generator tries to fool the discriminator, while the discriminator tries to correctly classify real and generated samples. At the ideal theoretical equilibrium, generated data follows the real data distribution and the discriminator cannot distinguish the two better than random guessing.

The notebook also explains mode collapse and two mitigation strategies:

- Mini-batch discrimination, which helps the discriminator identify a lack of diversity in generated samples.
- WGAN-GP, which provides smoother training signals through a Wasserstein objective and gradient penalty.

The three GAN variants discussed are:

- DCGAN: uses convolutional architectures for image generation.
- Conditional GAN: uses labels or other conditions to control generated samples.
- CycleGAN: performs unpaired image-to-image translation using cycle consistency.

## Evaluation

The models are evaluated on the FashionMNIST test set using:

- Test reconstruction MSE: lower is better.
- Test PSNR: higher is better.
- Class-specific MSE and PSNR for Pullover and Bag.
- Reconstruction visualizations.
- Random images generated by the VAE.
- Latent interpolation between two test images.

## Results

The experiments were run on an NVIDIA GeForce RTX 3060 Laptop GPU.

| Model | Test MSE | Test PSNR |
|---|---:|---:|
| FC-AE | 0.008607 | 20.6517 dB |
| VAE | 0.016658 | 17.7837 dB |

Class-specific reconstruction results were:

| Model | Class 2: Pullover MSE | Class 8: Bag MSE |
|---|---:|---:|
| FC-AE | 0.007653 | 0.014412 |
| VAE | 0.015869 | 0.024592 |

The FC-AE achieved lower reconstruction error and higher PSNR because it is optimized directly for deterministic reconstruction. The VAE produced higher reconstruction error because its objective also regularizes the latent distribution. However, the VAE provides capabilities that the FC-AE does not: random sample generation and smooth latent-space interpolation.

## Conclusion

The FC-AE and VAE both learned useful representations of FashionMNIST images. The FC-AE provided better reconstruction quality because it focused only on minimizing reconstruction error. The VAE produced a structured probabilistic latent space, allowing it to generate new images and perform latent interpolation. Together, the experiments demonstrate the difference between reconstruction-focused autoencoders and generative variational autoencoders.
